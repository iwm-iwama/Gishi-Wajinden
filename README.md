### これは何？
- **魏志倭人伝**（『三国志』魏書巻三十「烏丸鮮卑東夷伝」倭人条）を読み解くために作成した**AIプロンプト**です。
- **興味がある方は100%疑って使用してください**。

---

### 使用方法
- AIプロンプトにファイルを添付して送信することを想定しています。
  - Markdown (.md)
  - PDF (.pdf)

- 測量計算を含むため、推論プロセスには「**Deep Thinking**」など深い思考モードを利用してください。
  - Gemini、Copilot では、設定の違いで結果が大きく異なることがあります。
  - ローカルAIでは「20B以上」でないと期待値が得られないかも知れません。

---

### ハルシネーション対策
- **AIはあなたに同意します** → **要注意**。
  - 明確な基準値がないとき、AIは原文をソノママ引用して同意することが多いです。

- AIはデータを**端折り読み**することがあり、計算結果が期待値から大きく逸脱することがあります。
  - 通常は、推論プロセスを深くすることで改善するはずです。
  - 疑問があれば、Markdownファイルをテキストエディタで読み込み、節毎にプロンプト送信して部分検証してみてください。
  - 最悪、計算式をPython出力させて、別のAIで検証してください。
  - 以上、あきらかにハルシネーションならば、具体例を示して指摘するとAIは修正するはずです。
